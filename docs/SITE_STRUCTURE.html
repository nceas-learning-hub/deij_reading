🎨 Styling & Design

Color Palette (Inspired by NCEAS Learning Hub): - Primary Dark Green (#0C4537) - Navigation background - Primary Medium Green (#167B62) - Secondary elements, links - Light Green (#f3f8f7) - Backgrounds, highlights - Purple Accent (#bc40d4) - Interactive elements, hover states - Cream (#F4F3EE) - Cards and light backgrounds

Fonts: - Headings: Figtree (modern, geometric sans-serif) - Body: Nunito (readable, friendly sans-serif)

📄 Content Pages

index.qmd (Home/About)

  • Welcome message and site overview
  • Key themes of the reading list
  • Instructions for browsing and using resources
  • Call-to-action for contributions

readings.qmd (Readings Listing)

  • Displays all reading articles in a grid
  • Filterable by categories
  • Sorted by date (most recent first)
  • Includes search functionality

readings/*.qmd (Individual Articles)

Each reading article includes: - Title: Clear, descriptive title - Description: 1-2 sentence summary - Image: Cover image representing the topic - Categories: 2-3 tags for filtering and discovery - Date: When the reading was added - Content sections: - Overview - Key themes - Discussion prompts - Related topics

➕ Adding New Readings

  1. Create a new .qmd file in readings/

    • Use naming convention: reading-NN-topic-slug.qmd
    • Replace NN with sequential number

  2. Include YAML frontmatter:

    ---
title: "Your Reading Title"
description: "1-2 sentence summary"
author: "Your Name or DEIJ Reading List"
date: 2026-11-17
categories:
  - Topic Category 1
  - Topic Category 2
image: ../images/your-image.png
---

  3. Add content:

    • Overview section
    • Key themes (bulleted)
    • Discussion prompts (numbered)
    • Related topics

  4. Add an image:

    • Create a 6x4 aspect ratio image (e.g., 600x400 or 1200x800)
    • Save to images/ folder
    • Reference in YAML frontmatter

  5. Render:

    quarto render
